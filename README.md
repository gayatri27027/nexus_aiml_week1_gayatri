# my-project

# Problem Statement
Implement basic machine learning models from scratch using Python, NumPy, and Pandas, without using pre-built ML libraries.  
Models included:
1. Linear Regression – predicts continuous values.  
2. Logistic Regression – performs binary classification.  
3. K-Nearest Neighbors (KNN) – classifies data based on nearest neighbors.  

# Implementation Steps
1. Linear Regression – compute slope and intercept manually using gradient descent.  
2. Logistic Regression – compute weights and bias using gradient descent and the sigmoid function. 
3. KNN – calculate Euclidean distances, select k-nearest neighbors, and assign the most frequent class label.  
4. Save Models – trained models saved in '.pkl' format in a 'models/' folder.
